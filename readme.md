# Transformer 语言模型入门项目

本项目基于 Stanford CS336 Assignment 1，是我的独立学习实现与实验记录。

## 实现内容

- BPE 分词器
- Transformer 语言模型
- 模型训练、验证与文本生成
- TinyStories 和 OWT 数据集上的训练实验

## 项目说明

项目包含模型与训练代码，以及部分实验脚本。大型数据文件和模型检查点不上传到本仓库。

运行文本生成脚本前，需要先准备相应的分词器文件和训练检查点。后续将补充完整的运行命令与实验结果。
